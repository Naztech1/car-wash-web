# AquaPure | Premium Car Care Platform

AquaPure is a high-end, modern web application for a premier car wash and detailing service. Built with React and Vite, it features a sophisticated design system, seamless navigation, and a user-centric booking experience.

## ✨ Features
- **Modern UI/UX**: Premium aesthetic using the 'Outfit' & 'Montserrat' typography and a custom lime-navy color palette.
- **Service Showcases**: Detailed breakdown of precision washing, ceramic coating, and interior detailing.
- **Interactive Locations**: Find the nearest AquaPure center with our interactive map integration (Lusaka Hubs).
- **Membership Ecosystem**: Strategic pricing cards for various service tiers.
- **Precision Booking**: Multi-step booking flow for vehicle selection and scheduling.
- **Secure Authentication**: Professional split-screen Sign In page with mock API integration.
- **Contact Center**: Dedicated communication hub with localized contact details.

## 🚀 Tech Stack
- **Frontend**: React (Hooks, Router)
- **Styling**: Vanilla CSS (Custom Variable System) + Google Fonts (Material Symbols)
- **Build Tool**: Vite
- **Version Control**: Git & GitHub

## 🛠️ Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Naztech1/car-wash-web.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

## 📐 Design Philosophy
The platform is designed around the core principles of **Precision. Vitality. Purity.** It uses a unique "Droplet" brand language and technical isometric visuals to communicate excellence in automotive treatment.
